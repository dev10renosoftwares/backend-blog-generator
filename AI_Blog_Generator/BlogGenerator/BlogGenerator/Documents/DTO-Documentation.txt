# AI Blog Generator System – DTO Specification

## 1. Authentication DTOs

### 1.1 RegisterRequestDto

**Purpose:** Used to register a new user account.

```csharp
public class RegisterRequestDto
{
    public string UserName { get; set; }
    public string Email { get; set; }
    public string Password { get; set; }
}
```

### 1.2 LoginRequestDto

**Purpose:** Used to authenticate an existing user.

```csharp
public class LoginRequestDto
{
    public string Email { get; set; }
    public string Password { get; set; }
}
```

### 1.3 RefreshTokenRequestDto

**Purpose:** Used to request a new access token using a valid refresh token.

```csharp
public class RefreshTokenRequestDto
{
    public string RefreshToken { get; set; }
}
```

### 1.4 LogoutRequestDto

**Purpose:** Used to invalidate the user's refresh token during logout.

```csharp
public class LogoutRequestDto
{
    public string RefreshToken { get; set; }
}
```

### 1.5 AuthResponseDto

**Purpose:** Returned after successful registration or login.

```csharp
public class AuthResponseDto
{
    public int UserId { get; set; }
    public string UserName { get; set; }
    public string Email { get; set; }
    public string Role { get; set; }
    public int AvailableCredits { get; set; }
    public string AccessToken { get; set; }
    public string RefreshToken { get; set; }
    public DateTime ExpiresAt { get; set; }
}
```

### 1.6 MessageResponseDto

**Purpose:** Provides a generic success message for operations such as logout.

```csharp
public class MessageResponseDto
{
    public string Message { get; set; }
}
```

### 1.7 ValidationErrorResponseDto

**Purpose:** Represents validation errors returned by the API.

```csharp
public class ValidationErrorResponseDto
{
    public string Message { get; set; }
    public Dictionary<string, List<string>> Errors { get; set; }
}
```

### 1.8 ErrorResponseDto

**Purpose:** Represents a generic API error response.

```csharp
public class ErrorResponseDto
{
    public string Message { get; set; }
}
```

## Final DTO Count: 89

The DTO specification is designed for the **Angular frontend** communicating with the **ASP.NET Core Web API (.NET 8)** through REST APIs. DTOs are used to separate API request/response models from database entities and to provide appropriate data structures for authentication, profile management, AI blog generation, blog management, social interactions, notifications, credits, payments, support, and administration.
