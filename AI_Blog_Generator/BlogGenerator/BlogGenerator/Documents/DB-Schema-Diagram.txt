# Database Schema

## 1. Users

| Column            | Data Type     | Constraints               | Description            |
| ----------------- | ------------- | ------------------------- | ---------------------- |
| UserId            | int           | PK, Identity              | Unique user identifier |
| UserName          | nvarchar(100) | Required, Unique          | Username               |
| DisplayName //    | nvarchar(100) | Nullable                  | Public display name    |
| Email             | nvarchar(255) | Required, Unique          | User email             |
| PasswordHash      | nvarchar(max) | Required                  | Hashed password        |
| Role              | int           | Required                  | UserRole enum          |
| Bio               | nvarchar(500) | Nullable                  | User biography         |
| Website           | nvarchar(255) | Nullable                  | Personal website       |
| Location          | nvarchar(100) | Nullable                  | User location          |
| ProfilePictureUrl | nvarchar(500) | Nullable                  | Profile picture URL    |
| AvailableCredits  | int           | Required, Default = 100   | Available AI credits   |
| IsDeleted         | bit           | Required, Default = false | Soft delete flag       |
| CreatedAt         | datetime2     | Required                  | Account creation date  |
| UpdatedAt         | datetime2     | Nullable                  | Last profile update    |

# Account Deletion Behaviour

When a user deletes their account:

* Users.IsDeleted = true
* A record is inserted into **DeletedAccounts**
* Refresh tokens are revoked
* Login is blocked
* Existing blogs, payments, comments, likes, feedback, issues, notifications, and other historical records remain for auditing and platform integrity.
