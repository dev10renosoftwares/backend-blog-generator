1. Users:

| Column            | Data Type     | Constraints               | Description            |
| ----------------- | ------------- | ------------------------- | ---------------------- |
| UserId            | int           | PK, Identity              | Unique user identifier |
| UserName          | nvarchar(100) | Required, Unique          | Username               |
| Email             | nvarchar(255) | Required, Unique          | User email             |
| PasswordHash      | nvarchar(max) | Required                  | Hashed password        |
| Role              | int           | Required                  | UserRole enum          |
| ProfilePictureUrl | nvarchar(500) | Nullable                  | Profile image URL      |
| AvailableCredits  | int           | Required, Default = 100   | Current credit balance |
| IsDeleted         | bit           | Required, Default = false | Soft delete flag       |
| CreatedAt         | datetime2     | Required                  | Account creation date  |
| UpdatedAt         | datetime2     | Nullable                  | Last update date       |


2. RefreshTokens:

| Column     | Data Type     | Constraints               | Description                            |
| ---------- | ------------- | ------------------------- | -------------------------------------- |
| TokenId    | int           | PK, Identity              | Refresh token identifier               |
| UserId     | int           | FK → Users(UserId)        | Owner of the refresh token             |
| Token      | nvarchar(max) | Required                  | Refresh token value                    |
| ExpiryDate | datetime2     | Required                  | Token expiration date                  |
| IsRevoked  | bit           | Required, Default = false | Indicates whether the token is revoked |
| CreatedAt  | datetime2     | Required                  | Token creation date                    |

3. Blogs:

| Column      | Data Type     | Constraints        | Description                     |
| ----------- | ------------- | ------------------ | ------------------------------- |

| Content     | nvarchar(max) | Required           | Generated blog content          |

6. Plans:

7. Payments:

| Column                | Data Type     | Constraints        | Description               |

| CreditsPurchased      | int           | Required           | Credits added to the user |

10. DeletedAccounts:

| Column    | Data Type     | Constraints        | Description                 |
| --------- | ------------- | ------------------ | --------------------------- |
| DeletedId | int           | PK, Identity       | Deleted account identifier  |
| UserId    | int           | FK → Users(UserId) | Deleted user                |
| Email     | nvarchar(255) | Required           | User email at deletion      |
| Reason    | nvarchar(500) | Nullable           | Reason for account deletion |
| DeletedAt | datetime2     | Required           | Account deletion date       |

When a user deletes their account:

• Users.IsDeleted = true
• A record is inserted into DeletedAccounts
• Login is blocked
• Existing blogs, payments, feedback, and issues are retained
